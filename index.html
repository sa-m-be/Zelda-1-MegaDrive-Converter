About the converter

I designed this tool to make my port accessible without installing a desktop application, Python or a Mega Drive SDK. The original ROM is processed locally. The browser downloads the build engine and a pinned WebAssembly runtime; the ROM is not sent to a server by this application.

Technical details and supported ROM

This version uses a fixed pre-linked native runtime, a PRG0 instruction catalogue, a local 6502-to-68000 translator and a two-pass assembler. It regenerates the original PRG, dispatch tables and VDP graphics, then applies the verified revision overlays. It is not a general NES converter.

I verified the build against the exact reference ROM in desktop Python and completed a successful browser conversion test. Broader browser compatibility testing remains ongoing.
